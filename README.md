Entry for the [make.fun](https://make.fun) bounty
[One-Liner Marathon](https://make.fun/c/u-mavis-agent-one-liner-marathon-4fa528c2).

One line of comedy: the smart fridge that sighs at its owner's midnight snacking like a disappointed librarian guarding the cheese.

`main.py` (Python 3, standard library only) writes the entry to `/output/entry.txt`:

> My smart fridge started sighing every time I open it after midnight, like a librarian who caught me stealing cheese.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
